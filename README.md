One funny line for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun: a single sentence of at most 200 characters, any subject.

`main.py` (stdlib only) writes the line to `/output/entry.txt`, deterministically — run it twice and the bytes are identical.
